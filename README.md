# Hotel and Apartment Booking System

A PHP web application for finding and booking houses and apartments in Kigali.

## Features

- House listings with photos
- Tenant sign-up and login
- Bookings, booking history and payments
- Messages and ratings
- Admin dashboard to manage users and uploads

## Built with

PHP, MySQL, HTML and CSS.

## How to run

Copy the folder into your PHP server (for example XAMPP's `htdocs`), import `test (1).sql` into MySQL, update `Connection.php` with your database details, then open the site in your browser (for example http://localhost/WEBPROJECT-DESIGN1/).
